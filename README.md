## Getting started

1. `npm install`
2. `npm run dev`

## Quản trị

Mở `/admin` và chọn **Vào bản demo** để xem 29 màn hình quản trị.
Các màn dùng dữ liệu mẫu. Bản demo mô phỏng xác thực, phân quyền và các thao tác ghi dữ liệu trên giao diện.
